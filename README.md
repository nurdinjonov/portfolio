# ⚡ Xojiakbar Nurdinjonov — 3D Creative Portfolio Website

> **Linear & Apple Spatial Dark** estetikasi asosidagi zamonaviy, interaktiv 3D WebGL portfeli.
> **Muallif:** Xojiakbar Nurdinjonov — PDP Universiteti 2-kurs Software Development & Programming (C#) talabasi.

---

## 🌟 Asosiy Xususiyatlar (Key Features)

1. **🔮 3D Spatial Core (Three.js WebGL):**
   - 1,200+ zarrachali fazoviy maydon (particle field) va interaktiv CLR reaktori.
   - Kursor parallaksi va bosilganda to'lqinsimon impuls (shockwave effect).
   - `IntersectionObserver` orqali 0% batareya sarfi (ekrandan chiqqanda avtomatik to'xtaydi).

2. **📱 3D Smartphone Simulator (DailyPlanner & Focus):**
   - 3D flagman smartfon modeli (sichqoncha bilan erkin aylantirish va inersiyali orqaga qaytish).
   - Jonli ilova bo'limlari: *Rejalar*, *Google Calendar Oylik Taqvim*, *Pomodoro Fokus Taymeri* va *Duolingo Streaks + GitHub Heatmap*.
   - **To'g'ridan-to'g'ri Signed APK v1.2.1 yuklab olish** va konfetti animatsiyasi.

3. **💻 Brauzer Ichidagi Interaktiv Terminal (CLI):**
   - Zsh / Bash uslubidagi buyruqlar satri (`help`, `about`, `skills`, `projects`, `apk`, `architecture`, `contact`).
   - Klaviatura `Up/Down` tarixi va haqiqiy buyruqlar bajarilishi.

4. **📐 Clean Architecture & Muhandislik Matritsasi:**
   - C# .NET 9, MAUI, SQLite (bundle_green), ASP.NET Core va Linux infratuzilmasi uchun maxsus kvadranlar.
   - Clean Architecture qatlamlari diagrammasi modali.

5. **🎧 Taktil Web Audio Sintizatori:**
   - Og'ir media fayllarsiz, Web Audio API yordamida yaratilgan yoqimli mikro-klik va muvaffaqiyat tovushlari (ovozni o'chirish/yoqish imkoniyati bilan).

---

## 🛠 Texnologik Stek

- **Freymvork:** React 19 + TypeScript + Vite
- **3D Dvigatel:** Three.js
- **Stil & Dizayn:** Tailwind CSS (v4) + Linear Spatial Dark Tokens (`#030712`)
- **Ikonkalar:** Lucide React
- **Mikro-interaksiyalar:** Canvas Confetti, Web Audio API

## 🚀 Ishga Tushirish (Local Setup)

```bash
# Repozitoriyani klonlash
git clone https://github.com/xnurd/portfolio.git
cd portfolio

# Paketlarni o'rnatish
npm install

# Dev serverni yoqish
npm run dev

# Ishlab chiqarish (Production build)
npm run build
```
